# 🌐 Personal Portfolio Website

A responsive and interactive portfolio website built to showcase my frontend development skills, projects, and learning journey.

## 🎯 About The Project

This portfolio website represents my frontend development journey and provides an overview of my skills, projects, and achievements. It is designed with a focus on clean UI, responsive layouts, and smooth user experience across different devices.

## ✨ Features

- Fully responsive design for desktop, tablet, and mobile devices
- Smooth scrolling navigation
- Mobile-friendly hamburger menu
- About Me and Skills sections
- Interactive project showcase slider
- Resume viewing option
- Contact section
- Hover animations and modern UI effects
- Dynamic interactions using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Responsive Web Design
- CSS Flexbox
- Media Queries

## 📂 Website Sections

- Home
- About Me
- Skills
- Projects
- Contact

## ⚙️ Implementation Details

- Built responsive layouts using CSS Flexbox
- Implemented mobile responsiveness using Media Queries
- Created interactive UI elements using JavaScript
- Added smooth scrolling and animations for better user experience
- Optimized website layout for different screen sizes
